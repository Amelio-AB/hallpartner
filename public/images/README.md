# public/images/

Bildmaterial för Hallpartner Vision Site. Se undermapparna för specifika behov:

- `hero/` — stora bakgrundsbilder för hero-sektioner
- `projects/` — bilder till referensprojekt
- `details/` — detaljbilder (material, montage, konstruktion)

Tills riktiga bilder finns används CSS-baserade platshållare
(`.media-placeholder` i `src/styles/utilities.css`) — inga binära
platshållarbilder ska checkas in.

**Format:** `.webp` eller `.avif` i första hand, med `.jpg`-fallback vid behov.
**Namngivning:** beskrivande, kebab-case, t.ex. `industrihall-exteriör-01.webp`.
