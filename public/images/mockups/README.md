# public/images/mockups/

Skärmbilder/renderingar som visas i `src/components/BrowserMockup.astro`,
t.ex. i visions- och startsideförslags-sektionerna på startsidan.

**Behövs:**

- Skärmdump/rendering av `/startsideforslag/` (för startsidans förhandsvisning)
- Konceptuell visualisering av visionen (för visions-sektionen)

Dessa kan genereras internt (t.ex. skärmdump av den färdiga sidan) i takt med
att designen färdigställs — de är inte kundmaterial och kräver inget
godkännande från Hallpartner.
