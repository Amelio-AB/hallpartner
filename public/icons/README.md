# public/icons/

Linjeikoner enligt docs/DESIGN_SYSTEM.md ("Ikoner"): enhetlig stil, en
accentfärg, SVG-format.

För närvarande ritas enkla platshållarikoner direkt i CSS
(`StrengthGrid.astro`, `ResultsGrid.astro`). När ett riktigt ikonset finns
kan dessa ersättas med SVG-filer i denna mapp, t.ex. `check.svg`,
`building.svg`, `document.svg`.
