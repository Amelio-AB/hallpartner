# public/videos/

Valfritt bakgrundsvideomaterial för hero-sektionen (`src/components/Hero.astro`
stödjer för närvarande en bild-platshållare; video kan läggas till senare).

**Riktlinjer:**

- Kort loop (10–20 sek), ingen ljudspår som krävs för förståelse
- Komprimerad `.mp4` (H.264) + ev. `.webm`
- Måste respektera `prefers-reduced-motion` (visa stillbild istället)
