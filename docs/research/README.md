# Hallpartner – pre-production research

> **Status:** Arbetsmaterial. Inte beslutad produktionsspecifikation.
>
> **Branch:** `research/pre-production-analysis`
>
> Materialet i denna mapp får inte användas som verksamhetsbevis innan Peter/Jimmy har verifierat relevanta uppgifter.

## Syfte

Samla sådant som kan utredas medan Hallpartner återkommer med affärsfakta.

Arbetet får:

- kartlägga befintligt material
- jämföra tidigare offertarbete med den beslutade UX-referensen
- identifiera claims som behöver bevis
- inventera befintliga URL:er och bilder
- föreslå vilka frågor som sannolikt hör hemma före respektive efter första kontakt

Arbetet får inte:

- hitta på Hallpartners leveransomfattning
- anta certifieringar, garantier, erfarenhet eller geografisk leveransförmåga
- låsa slutlig sitemap
- låsa slutliga offertfrågor
- använda Amelio Quote Engine som teknisk motor för Astro-sajten
- använda CSS/design från den gamla visionssajten som beslutad produktionsdesign
